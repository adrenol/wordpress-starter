## When building WordPress website

- Use Gutenberg blocks
- Use TailwindCSS
- Generate realistic website content for demonstration purposes. Use neutral, fictional contact information (e.g., hello@example.com, +7 (700) 123-4567). Do not include instructions, placeholders, or editorial notes. The content should be fully written as if it were final, but suitable for a demo or showcase site
- You MUST let WordPress admin edit content where it is safe to do
- Ensure the website is responsive and mobile-friendly
- Ensure consistent spacing. Identical components (e.g. cards) must have the same padding and margin.
